# Glossary

| Term            | Meaning                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| Browser session | The open tabs, selected tab, split panes, and temporary browser screens for the current window.               |
| Tab             | One page with its own navigation history and page state.                                                      |
| Tab slot        | One entry in the tab strip or rail. A split shares one slot with a tab segment for each pane.                 |
| Split           | Two to four tabs shown together in columns, rows, or a grid, with a focused pane and adjustable dividers.     |
| Pane            | One page area in a split.                                                                                     |
| Compact mode    | A view that hides the toolbar and tabs until the pointer reaches their window edge.                           |
| Chrome          | The browser's local controls surrounding web pages.                                                           |
| Tab layout      | The placement of the tab strip or rail: top, left, or right.                                                  |
| Favorites       | Tabs shown as an icon grid at the top of the tab list. They persist and reset to their home page when closed. |
| Pinned tab      | A saved tab with a home page. Closing it puts it to sleep and returns it to its home page.                    |
| Folder          | A named, collapsible group of pinned tabs and other folders. A folder and everything in it share one space.   |
| Today           | Ordinary tabs below the pinned tabs. They persist and move to the archive when unused.                        |
| Archive         | A list of closed or expired Today tabs that a user can filter, restore, or remove.                            |
| Sleeping tab    | A tab whose page view is unloaded to free memory. It reloads, with its history, when selected.                |
| Space           | A named, colored set of tabs, folders, and favorites with its own profile. One space shows at a time.         |
| Profile         | The cookies, logins, cache, and site data of one space, kept in its own Electron session partition.           |
| Route           | A rule that opens new tabs for a site, and its subdomains, in a specific space.                               |
| Media card      | A sidebar card for a playing or paused tab that is not on screen, with Play/Pause and Mute.                   |
